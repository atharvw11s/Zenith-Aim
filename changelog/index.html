v6.3.0

v3 fixes plus the edge-to-edge redesign

Nov 15, 2026
  • FixedRivals conversion uses camera sensitivity and does not scale with FOV.
  • FixedArsenal conversion uses FOV-based yaw.
  • AddedDPI input and a cm/360 readout on the sensitivity converter.
  • ChangedFOV conversion paths and defaults cleaned up.
  • AddedFocus presets: Balanced, Flick day, Track day, and Switch day.
  • AddedShare menu: copy the routine as text, copy a playlist link, or copy workshop searches for every task.
  • AddedEach task card has its own Workshop link.
  • FixedWarmup tracking scores time on target. Flicking and switching are click modes again.
  • ChangedFull-bleed layout everywhere — the Options panel now sits in the left corner and content stretches to the screen edges instead of floating in a centered box.
  • ChangedContent is anchored to the screen edges on every page, while the landing hero heading stays centered as the centerpiece of the home page.
  • ChangedConverters page shows the sensitivity and FOV converters side by side on wide screens.
  • RemovedThe 'Z' logo tile is gone from the header and nav — the favicon is now a crosshair mark.
  • RemovedAll input placeholder text removed across auth, name entry, warmup and converter fields.
  • AddedFully static-host ready: sign-in (Google/GitHub OAuth + player name) and the live weekly leaderboard now run client-side on Firebase, sharing the same data as the original site.
  • AddedPersonal bests for the 3D warmup are stored per player in Firebase and merged with local storage.
  • AddedGitHub Pages deployment: static export on the /Zenith-Aim base path. Styles and scripts live in next/, route data in data/.
  • AddedThis changelog page.
